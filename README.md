# dudu 画面感内容工具 · H5

本仓库是微信小程序「dudu画面感内容工具」的 **H5 承载页**——免费钩子 + 查看 / 成交入口。

| 页面 | 角色 | 能否生成内容 |
|---|---|---|
| `index.html` | 朋友圈文案工具（免费钩子） | ⛔ **纯本地模板**：人工骨架 + 字符串替换 + 排版优化，零网络、零 AI（2026-09-30 起与小程序 B1 同构） |
| `comic.html` | 画面感内容定制样板间（成交页） | ⛔ 只展示成品、收需求（`h5_request`），**不调出图、不做自助生成** |

纯静态，无需构建，直接丢到任意静态托管即可运行。后端地址见 `assets/config.js`（`apiReq` 供样板间收需求用；`api` 为历史字段，文案页已不再调用）。

> 合规：两个页面都**不提供任何 AI 自助生成**（个人主体不做深度合成，无需算法备案）。
> 模板为人工编写的成品骨架，运行时仅做文字替换；样板间仅售卖已完成的成品内容。
> 付款复用小程序内个人虚拟支付（`comic_pdf` ¥66 / `comic_web` ¥88）。

源工程：`comic_miniapp/h5/`（同步自本地工程，仅静态前端，不含云函数）。

# dudu 画面感内容工具 · H5

本仓库是微信小程序「dudu画面感内容工具」的 **H5 承载页**——AI 生成能力外迁后的统一查看 / 成交入口。

| 页面 | 角色 | 能否生成内容 |
|---|---|---|
| `index.html` | 朋友圈文案工具（免费钩子） | ✅ 调云函数 `ai_gen` 的 H5 通道（按日额度限流） |
| `comic.html` | 画面感内容定制样板间（成交页） | ⛔ 只展示成品、收需求，**不调出图** |

纯静态，无需构建，直接丢到任意静态托管即可运行。后端地址见 `assets/config.js`（`window.H5_CONFIG` 的 `api` / `apiReq`）。

> 合规：本页常驻「AI 生成」标识与免责声明；样板间不提供自助生成，仅售卖已完成的成品内容，
> 不需要算法备案。付款复用小程序内个人虚拟支付（`comic_pdf` ¥66 / `comic_web` ¥88）。

源工程：`comic_miniapp/h5/`（同步自本地工程，仅静态前端，不含云函数）。
